Magpiary pipeline

An app anyone can download to their Mac. Pair an iPhone once. From then on, sharing a reel or Threads post to Magpiary turns it into an organized, searchable note on their own machine, with their own choice of AI.

iPhone runs on the phone Mac runs on the user's Mac Cloud leaves the Mac, only if the user opts in

Where everything runs

There is no server of ours, and no iCloud. The phone strips the link and keeps it in a queue on the phone itself. That queue is handed straight to the Mac whenever the phone is on the same Wi-Fi. Tailscale arrives later, and only for viewing the full hub away from home. The user's Mac does all the downloading and processing. The only outside calls are to Instagram and, in Balanced or Easiest, the AI provider the user picked.

The pipeline, step by step

Each stage is labeled with where it runs. Dashed boxes are decisions. Red outcomes end the run for that item.

1

Capture

iPhone
  1. Share → MagpiaryFrom Instagram or Threads, via a Shortcut in the share sheet.
  2. Strip the link on the phoneBefore anything is saved, the Shortcut cuts everything after the post ID: igsh, igshid, utm_* and xmt. instagram.com/reel/Example0013/?igsh=… becomes instagram.com/reel/Example0013/. The identifier never leaves the phone.
  3. Add a note?
    SkipOne tap and done. This is the default.
    NoteType or dictate a line. It's saved with the item.
  4. Added to the queue on the phoneA small file in On My iPhone / Shortcuts / Magpiary, holding the clean link, the time, the source app and the note. It stays on the device, uses no iCloud, and is never lost even if every send fails.
  5. Can the phone reach the Mac right now?It tries the Mac's address on the local network.
    YesSends everything waiting in the queue. The Mac confirms each item, and only confirmed items leave the queue.↓ stage 2
    NoStays queued. The banner reads "Saved · will send when you're home."
  6. Automatic catch-up on home Wi-FiA Shortcuts automation runs whenever the phone joins the user's home network and sends the whole queue, with no tap needed. Every new share also retries anything left over.

First-run setup for a new user

The target is under five minutes from download to the first filed reel, with no terminal.

  1. Install2 min

    Paste one command into Terminal, from our own Homebrew tap or an install script. It sets up yt-dlp, ffmpeg and a background service, then opens the setup page in the browser. There's no .app to download, so there's no Apple signing and no Gatekeeper warning.

  2. Pick a preset1–10 min
    • Balanced (recommended): paste a Claude, OpenAI or Gemini key.
    • Easiest: paste a free Gemini key.
    • Private: a one-time download of local models, roughly several GB.
  3. Pair the iPhone2 min
    • Scan the first QR code to add the Magpiary Shortcut.
    • Scan the second to hand it the Mac's address and a pairing key.
    • Set up the "When I join home Wi-Fi" automation by following the on-screen steps.
  4. Connect Instagram, only if needed1 min

    Skippable. If logged-out fetches start failing, the hub offers this. The user picks their browser, and macOS asks permission for Magpiary to read that browser's login, which the page explains first.

  5. Send a test reel1 min

    Share any reel. The app shows it moving through the stages live, and the first record appears in the hub.

  6. Optional extraslater
    • Import past saves from an Instagram data export.
    • Turn on receipts.
    • Set up Tailscale for access away from home.

Risks to plan for

  • Meta's terms

    Downloading posts breaks Instagram's terms of service. youtube-dl was hit with a DMCA takedown on GitHub in 2020, and it was reinstated. Mitigation: call yt-dlp rather than shipping our own scraper, use only the user's own login, rate-limit downloads, frame it as a personal archive, and host no content anywhere.

  • yt-dlp breaking

    When Instagram changes something, every user breaks on the same day. Mitigation: the app updates yt-dlp separately from itself, and shows a clear "fetching is down, your shares are queued" state.

  • No Apple signing

    An unsigned .app downloaded from the web is blocked by Gatekeeper, and Homebrew's main cask repository disables casks that fail Gatekeeper from September 2026. Plan: ship no .app at all. Installing from Terminal doesn't trigger Gatekeeper's download check, and every screen is a local web page. The cost is one Terminal step during setup.

  • Phone and Mac must meet

    With no middleman, a link only moves when the phone can reach the awake Mac. Shares made away from home wait until you're back on the same network. Mitigation: the phone's queue is permanent and visible, and catch-up is automatic.

  • Home network details

    The Mac's address can change, and some routers isolate devices from each other. Mitigation: use the Mac's .local name rather than its IP, and give the setup page a "test from your phone" button.

  • macOS permissions

    The receiver needs the macOS firewall to allow incoming connections, and the opt-in login fallback needs Keychain access. Test early which prompts appear, so setup can walk users through them.

  • Free tiers move

    Gemini's free limits and data terms can change. The Easiest preset should show the user's remaining quota and say plainly where their data goes.

  • Support load

    Most issues will be Instagram logins and permissions. A built-in "diagnose" screen that checks each stage saves a lot of GitHub issues.

Decisions still open

  • Name

    Magpiary is a working name. Check it isn't taken before the repo goes public.

  • License

    MIT matches /watch, so its code can be reused with attribution. AGPL would stop someone turning it into a closed hosted service.

  • Install method

    Our own Homebrew tap with a formula, which gives clean updates, or a one-line install script that sets up Python with uv. Both avoid Gatekeeper.

  • Anonymous fetch success rate

    How often a logged-out Mac on home internet gets each reel without hitting a login wall. Test with 20 to 30 real links before deciding how prominent "Connect Instagram" should be.

  • Settled

    Balanced is the default preset. Links queue on the phone and go straight to the Mac, with no iCloud and no server. All downloading happens on the Mac. Tracking IDs are stripped on the phone. There's no paid Apple account.

  • Later, with the real hub

    Tailscale for opening the hub from the phone on any network. It isn't used to move links. Email routes are dropped.
